# Hamseda (اپ اندروید)

اپ یه WebView امنه که فقط `https://hamseda.vibracenter.ir` رو باز می‌کنه.

## چی داره
- صفحه‌ی بارگذاری با لوگو، حلقه‌های متحرک، نوار پیشرفت و فونت سهل، بعد نمایش تمیز سایت
- سایت زیر نوار بالای گوشی شروع می‌شه، نه توش
- رنگ نوار بالا، نوار پایین و اعلان‌ها خودکار با تم روشن/تاریک سایت عوض می‌شه
- بدون اینترنت یا خطا: صفحه‌ی استایل‌دار «اینترنتت مشکل داره!» با دکمه‌ی رفرش
- اینترنت خیلی ضعیف: صفحه تار می‌شه و پیغام «اتصالت خیلی ضعیفه» میاد
- مجوز میکروفن، دوربین، اعلان و هدفون موقع اولین اجرا
- توی اتاق، اگه از برنامه بیرون بری از اتاق خارج نمی‌شی (بدون پنجره کوچک) و اعلان «اتاق در پس‌زمینه فعاله» میاد
- تا وقتی اپ کامل بسته نشده، دعوت‌ها و اعلان‌های سایت دریافت می‌شن. با «خروج» توی اعلان یا کشیدن اپ از لیست برنامه‌ها همه چیز خاموش می‌شه
- اعلان‌های سایت با همون عنوان، متن و عکس، و با لمس، همون صفحه رو باز می‌کنن
- دعوت به اتاق مثل تماس زنگ می‌خوره (با لرزش، بر اساس حالت بی‌صدا/لرزشِ گوشی) تا لمس، پیوستن یا رد کردن

## اتصال سایت به اپ (برای اعلان و زنگ دعوت)
اپ خودکار `new Notification(...)` سایت رو می‌گیره. برای دعوت به اتاق (که زنگ بخوره) توی کد سایت، هر جا دعوت دریافت می‌شه:

```js
if (window.HamsedaApp) {
  HamsedaApp.ring({ title: 'دعوت به اتاق', body: 'علی تو رو به اتاق «گپ شبانه» دعوت کرد', url: '/room/12', icon: '/img/avatar.png', tag: 'invite-12' });
}
```

برای اعلان معمولی `HamsedaApp.notify({ title, body, url, icon, tag })` یا همون `new Notification(title, { body, icon, tag, data: { url } })` .
`url` و `icon` فقط از خود سایت قبول می‌شن.

## امنیت
- فقط HTTPS؛ هر خطای گواهی رد می‌شه
- لینک‌های بیرون از vibracenter.ir توی مرورگر گوشی باز می‌شن
- فقط hamseda.vibracenter.ir به میکروفن، دوربین و ارتباط با اپ دسترسی داره
- بدون دسترسی به فایل، بدون بک‌آپ، بدون دیباگ وب

## ساخت نسخه‌ی امضاشده برای کافه‌بازار، مایکت و گوگل‌پلی
نسخه‌ی debug رو استورها قبول نمی‌کنن. ساخت release امضاشده:

1. توی ریپوی گیت‌هاب: Settings ← Secrets and variables ← Actions ← New repository secret
2. چهار Secret بساز: `KEYSTORE_BASE64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD` (مقدارها توی فایل `GITHUB-SECRETS.txt`)
3. Actions ← Build APK ← Run workflow
4. پایین صفحه‌ی همون اجرا، بخش Artifacts، دو تا فایل هست (روی اسمشون بزن تا زیپ دانلود بشه، بازش کن):
   - `Hamseda-APK-for-Bazaar-Myket` ← داخلش `Hamseda-release.apk` برای کافه‌بازار و مایکت
   - `Hamseda-AAB-for-GooglePlay` ← داخلش `Hamseda-release.aab` برای گوگل‌پلی

منطق ساخت توی `ci/build-release.sh` هست (با زیپ آپدیت می‌شه). فایل `.github/workflows/build-apk.yml` فقط کوتاهه و باید یک بار دستی توی سایت گیت‌هاب جایگزین بشه، چون پوشه‌ی `.github` موقع آپلود زیپ گاهی جا می‌مونه: فایلش رو باز کن ← مداد ← کل محتوا رو پاک کن و محتوای جدید رو بچسبون ← Commit. اولین مرحله‌ی ساخت باید «Build signed release (APK + AAB)» باشه. اگه ارور «A DEBUG build was requested on GitHub» اومد، یعنی هنوز workflow قدیمی توی ریپوئه.

فایل `.jks` و `GITHUB-SECRETS.txt` رو هیچ‌وقت توی ریپو آپلود نکن (`.gitignore` جلوش رو می‌گیره) و یه نسخه‌ی پشتیبان جای امن نگه دار. با گم شدنش دیگه نمی‌تونی آپدیت اپ رو توی استورها منتشر کنی.
هر بار ساخت، شماره‌ی نسخه (versionCode) خودکار بیشتر می‌شه، پس هر آپلود جدید از قبلی بالاتره.

اگه Secretها ست نشن یا اشتباه باشن، workflow با یه پیغام قرمز واضح متوقف می‌شه (دیگه بی‌صدا نسخه‌ی debug نمی‌سازه). بعد از ساخت موفق، توی صفحه‌ی خلاصه‌ی اجرا نوشته می‌شه «Signed with the Hamseda release key» و اثرانگشت امضا.

## اگه موقع نصب نوشت «App not installed as package conflicts with an existing package»
یعنی روی گوشی یه Hamseda با امضای دیگه (نسخه‌ی debug قبلی) نصبه و اندروید اجازه‌ی جایگزینی نمی‌ده. فقط یک بار لازمه پاکش کنی:
1. Settings ← Apps ← Hamseda ← Uninstall (اگه گزینه‌ی «برای همه کاربران» بود، اون رو بزن)
2. گوشی‌های شیائومی: «Dual apps / Second space» و پروفایل کاری رو هم چک کن؛ نسخه‌ی اونجا هم باید پاک بشه
3. بعد `app-release.apk` رو نصب کن

از این به بعد همه‌ی نسخه‌ها با همین یک کلید امضا می‌شن و روی هم آپدیت می‌شن، بدون پاک کردن.

## تنظیمات
فایل `app/src/main/java/ir/vibracenter/hamseda/Config.kt`:
- `BLOCK_SCREENSHOTS`: `true` یعنی اسکرین‌شات از اپ گرفته نمی‌شه
- `NOTIFY_WHEN_FOREGROUND`: `false` یعنی وقتی اپ جلوی چشمته اعلان سایت نشون داده نشه
- `KEEP_ALIVE`: `false` یعنی اپ توی پس‌زمینه فعال نمی‌مونه (فقط داخل اتاق)
- `INVITE_RING_MS`: مدت زنگ خوردن دعوت
- `WEAK_LATENCY_MS`: حد ضعیف بودن اتصال (میلی‌ثانیه)
