# Hamseda (اپ اندروید)

اپ یه WebView امنه که فقط `https://hamseda.vibracenter.ir` رو باز می‌کنه.

## چی داره
- صفحه «در حال بارگذاری…» و بعد نمایش تمیز سایت، زیر نوار بالای گوشی
- بدون اینترنت یا خطا: صفحه استایل‌دار «اینترنتت مشکل داره!» با دکمه رفرش (صفحه پیش‌فرض مرورگر هیچ‌وقت نشون داده نمی‌شه)
- اینترنت خیلی ضعیف: صفحه تار می‌شه و پیغام «اتصالت خیلی ضعیفه» میاد
- اجازه میکروفن، دوربین، اعلان و بلندگو/هدفون موقع اولین اجرا
- توی اتاق، اگه از برنامه بیرون بری، از اتاق خارج نمی‌شی (بدون پنجره کوچک) و یه اعلان «اتاق در پس‌زمینه فعاله» میاد
- اعلان‌های خود سایت به‌صورت اعلان موبایل نشون داده می‌شن

## امنیت
- فقط HTTPS؛ هر خطای گواهی رد می‌شه
- لینک‌های بیرون از vibracenter.ir توی مرورگر گوشی باز می‌شن، نه داخل اپ
- فقط خود hamseda.vibracenter.ir به میکروفن/دوربین و ارتباط با اپ دسترسی داره
- بدون دسترسی به فایل، بدون بک‌آپ، بدون دیباگ وب

## گرفتن APK
همون روش GitHub Actions: محتویات این پوشه رو توی یه ریپوی جدید آپلود کن (پوشه `.github` هم باشه)، تب Actions ← Build APK ← Run workflow، و بعد APK رو از Artifacts بردار.

## تنظیمات
فایل `app/src/main/java/ir/vibracenter/hamseda/Config.kt`:
- `BLOCK_SCREENSHOTS`: `true` یعنی اسکرین‌شات از اپ گرفته نمی‌شه
- `NOTIFY_WHEN_FOREGROUND`: `false` یعنی وقتی اپ جلوی چشمته اعلان سایت نشون داده نشه
- `WEAK_LATENCY_MS`: حد ضعیف بودن اتصال (میلی‌ثانیه)
